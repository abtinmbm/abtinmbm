## Right now

The software is done, and on a Raspberry Pi Pico 2 it now hears a fault in a real fan and cuts the fan's power by itself. Next: an hour-long false-stop test, ten trials per fault and a demo video.

## Shipped

🛩️ **[Image Stitcher](https://github.com/UWARG/autonomy-monorepo/pull/215)** for the Waterloo Aerial Robotics Group: it merges photos arriving out of order from several drones into one GPS-referenced map. Merged into the team's main branch after four rounds of review. In simulation, photos line up to 4.0–8.3 cm on average, and the map lands closer to its true position than the GPS error itself.
